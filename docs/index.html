01

그림이 먼저입니다

02

도구는 둘뿐

넘파이와 맷플롯립만 씁니다. 고수준 라이브러리가 계산 과정을 감추지 않도록, 화살표 하나까지 직접 그립니다.

03

내 손으로 만든 도구

2장에서 lautils를 직접 만들어 끝까지 씁니다. 3차원을 마우스로 돌려 보고 싶으면 interactive=True 한 마디면 됩니다. 나머지 코드는 그대로입니다.
