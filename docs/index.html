웹북 읽기 1장부터 시작

이 책의 방식

개념 → 손 계산 → 넘파이 → 그림. 네 박자가 한 세트입니다.

01

그림이 먼저입니다

행렬식은 넓이의 배율로, 고유벡터는 방향이 변하지 않는 축으로, 특이값 분해는 서서히 드러나는 이미지로 확인합니다.

02

도구는 둘뿐

넘파이와 맷플롯립만 씁니다. 고수준 라이브러리가 계산 과정을 감추지 않도록, 화살표 하나까지 직접 그립니다.

03

내 손으로 만든 도구

2장에서 lautils.py를 직접 만들어 끝까지 씁니다. 대화형 3차원이 필요하면 같은 API의 tuvis.py로 바꾸면 됩니다.

04

인공지능으로 이어집니다

어텐션은 내적, 차원 축소는 특이값 분해, 기울기 소실은 고유값. 각 장이 모델의 어느 부분에 닿는지 짚습니다.

맛보기

행렬 하나가 평면을 어떻게 바꾸는지, 열 줄이면 볼 수 있습니다.

import numpy as np
from lautils import *

A = np.array([[1.2, 0.8],
              [0.3, 1.4]])

fig, ax = new_axes(xlim=(-4, 4), ylim=(-4, 4))
draw_grid(ax, None, n=3, color='lightgray')   # 원래 격자
draw_grid(ax, A, n=3)                        # A로 변환된 격자
draw_polygon(ax, transform(A, UNIT_SQUARE))    # 넓이 = |det A|
draw_vector(ax, A[:, 0], color='crimson')     # e1이 옮겨 간 자리
draw_vector(ax, A[:, 1], color='royalblue')   # e2가 옮겨 간 자리

목차

13개 장이 하나의 흐름으로 이어집니다.
