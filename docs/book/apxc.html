넘파이 선형대수 레퍼런스

이 책에서 사용한 넘파이 기능을 한자리에 모았다. 필요할 때 찾아보는 용도로 쓰면 된다.

배열 만들기

함수 하는 일
np.array(리스트)리스트로부터 배열 생성
np.zeros((m,n))0으로 채운 배열
np.ones((m,n))1로 채운 배열
np.eye(n)\(n\times n\) 단위행렬
np.diag(v)1차원 \(\to\) 대각행렬 / 2차원 \(\to\) 대각성분 추출
np.arange(a,b,s)\(a\)부터 \(b\) 전까지 \(s\) 간격
np.linspace(a,b,n)\(a\)부터 \(b\)까지 균등하게 \(n\)개
np.column_stack([...])배열들을 열로 세워 붙이기
np.vstack / np.hstack세로 / 가로로 이어 붙이기
np.triu / np.tril상삼각 / 하삼각 부분만 남기기
np.vander(x, n)반데르몬드 행렬 (다항식 회귀)
rng = np.random.default_rng(42)난수 생성기 (시드 고정)

배열의 구조

A.shape각 축의 원소 수
A.ndim축(차원)의 개수
A.size전체 원소 수
A.dtype원소의 자료형
A.T전치 (1차원 배열에는 효과 없음)
A.reshape(m, n)모양 바꾸기 (\(-1\)은 자동 계산)
A.flatten()1차원으로 펴기
A[:, np.newaxis]축 추가 (열벡터 만들기)
A.copy()복사 (슬라이싱은 뷰임에 주의)

연산

A + B, A - B성분별 덧셈·뺄셈
A * B성분별 곱 (아다마르 곱)
A @ B, np.matmul행렬 곱
u @ v내적 (두 1차원 배열일 때)
np.outer(u, v)외적 (열\(\times\)행 \(\to\) 행렬)
np.cross(u, v)3차원 가위곱
np.dot, np.inner내적 (차원에 따라 동작이 다름)
A.sum(axis=k)\(k\)번째 축을 따라 합 (그 축이 사라짐)
A.mean / std / max / min통계량 (axis 지정 가능)
np.where(조건, a, b)조건에 따라 선택
np.allclose(A, B)오차 범위 안에서 같은지 판정

np.linalg 모듈

함수 하는 일 장
norm(v)노름(길이). ord=1, np.inf 지정 가능4
norm(A, 'fro')프로베니우스 노름11
det(A)행렬식7
inv(A)역행렬 (되도록 solve를 쓸 것)6
solve(A, b)\(\mm{A}\vv{x}=\vv{b}\)의 해6, 8
matrix_rank(A)계수(랭크)8
matrix_power(A, k)\(\mm{A}^k\)10
eig(A)고유값·고유벡터 (일반 행렬)9
eigh(A)고유값·고유벡터 (대칭행렬, 더 빠름)9
eigvals(A)고유값만9
svd(A)특이값 분해11
pinv(A)유사 역행렬12
lstsq(A, b)최소제곱 해12
qr(A)QR 분해12
cond(A)조건수6, 11

자주 하는 실수 모음

실수 바로잡기
A * B로 행렬 곱을 계산A @ B를 쓴다
1차원 배열에 .T를 적용reshape(-1,1)로 2차원으로 만든다
eig의 고유벡터를 V[k]로 접근V[:, k]가 맞다 (열에 담김)
svd의 세 번째 값을 \(\mm{V}\)로 착각\(\mm{V}\tp\)다. Vt로 이름 짓자
det(A) == 0으로 비교np.isclose나 matrix_rank를 쓴다
정수 배열에 실수를 대입dtype=float로 만든다
슬라이싱 결과를 수정원본이 바뀐다. .copy()를 쓴다
norm(..., axis=1)에서 keepdims 누락브로드캐스팅 방향이 틀어진다
arccos에 1을 넘는 값 입력np.clip(x, -1, 1)로 감싼다
정규방정식 \((\mm{A}\tp\mm{A})\inv\)을 직접 계산lstsq나 QR을 쓴다
inv(A) @ b로 방정식 풀이solve(A, b)가 빠르고 정확하다
PCA 전에 중심화를 빠뜨림X - X.mean(axis=0)

fig, ax = plt.subplots(m, n)격자 형태의 그림판 만들기

ax.scatter(x, y)산점도
ax.quiver(x, y, u, v, ...)화살표 (벡터)

ax.contourf(X, Y, Z)등고선 채우기

ax.grid(True, alpha=0.3)격자 표시
