실습 환경 준비

이 책의 모든 예제는 넘파이와 맷플롯립만 있으면 실행된다. 가장 쉬운 방법은 설치가 필요 없는 구글 코랩이고, 내 컴퓨터에 직접 갖추고 싶다면 파이썬과 두 패키지를 설치하면 된다.

구글 코랩 (권장)

  1. 브라우저에서 colab.research.google.com에 접속한다.
  2. 구글 계정으로 로그인한 뒤 [새 노트]를 선택한다.
  3. 코드 셀에 예제를 입력하고 Shift + Enter로 실행한다.

넘파이·맷플롯립·plotly가 이미 설치되어 있으므로 바로 시작할 수 있다. 버전은 다음으로 확인한다.

import numpy as np
import plotly
print(np.__version__, plotly.__version__)

자주 만나는 문제

그림 속 한글이 깨져 보인다

맷플롯립의 기본 폰트에 한글이 없어서 생기는 문제다. 이 책은 그림 속 문자열을 모두 영어로 적어 두었으므로 이 문제를 겪지 않는다. 한글을 쓰고 싶다면 폰트를 지정해야 한다.

import matplotlib.pyplot as plt

# macOS
plt.rcParams['font.family'] = 'AppleGothic'
# 윈도우
# plt.rcParams['font.family'] = 'Malgun Gothic'
# 코랩 (나눔폰트 설치 후)
# plt.rcParams['font.family'] = 'NanumGothic'

plt.rcParams['axes.unicode_minus'] = False    # 마이너스 기호 깨짐 방지

그림이 나타나지 않는다

tuvis의 그림은 fig.show()로 띄운다. 스크립트로 실행하면 기본 브라우저에 새 탭이 열리고, 주피터·코랩에서는 셀 아래에 바로 나타난다. 맷플롯립으로 그린 일반 그래프는 plt.show()가 필요하다.

ModuleNotFoundError: No module named 'tuvis'

tuvis.py가 현재 작업 디렉터리에 없는 경우다. 파일 위치를 확인하거나 경로를 추가한다.

import os, sys
print(os.getcwd())                 # 현재 작업 디렉터리 확인
sys.path.append('/파일이/있는/경로')

계산 결과가 책과 미세하게 다르다

부동소수점 연산의 결과는 하드웨어와 라이브러리 버전에 따라 마지막 자릿수가 달라질 수 있다. np.allclose()로 비교하면 문제가 없다. 난수를 쓰는 예제는 default_rng(42)처럼 시드를 고정했으므로 같은 값이 나와야 하지만, 넘파이 주버전이 바뀌면 난수 알고리즘이 달라질 수 있다.

고유벡터의 부호가 책과 반대다

정상이다. 9장에서 설명했듯 \(\vv{v}\)가 고유벡터면 \(-\vv{v}\)도 고유벡터이므로, 라이브러리가 어느 쪽을 돌려줄지는 정해져 있지 않다. 부호에 의존하는 코드를 작성하지 않도록 주의하자.
